A smaller home on the web

29 September 2026 · Godly K Mathews

This website has a simpler shape now: a few HTML pages, a little CSS, and room for words.

The portfolio used to be a React application with a long scrolling page. Now, projects, experience, and open-source contributions each have their own place. The site uses system fonts and ordinary links. There is no JavaScript to load and no build step to run.

A place for notes

Much of my work lives in repositories or a short line on a résumé. This blog gives me space to write about it in more detail.

There are a few areas I'd like to explore here: Malayalam language technology, local AI, web and mobile development, and small hardware experiments. Those interests already run through my projects and my time at ICFOSS.

Keeping it small

The aim is a site that's easy to read and easy to maintain. Each post is a page you can link to directly, and there's an RSS feed for following along.

For now, this is the first note. If something here interests you, say hello.
